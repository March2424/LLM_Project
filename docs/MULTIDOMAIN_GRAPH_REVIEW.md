| 项目 | 对齐结论 |
| --- | --- |
| 学生任务 | 相同：只学上下文选择，不训练译文 |
| 标签 | 相同：完整rationale＋selected_ids；理由和动作都参与loss |

| 记忆 | 相同机制：STM3、LTM top2、summary_step5、未审run隔离 |
| 角色最少证据 | 已修正公共Teacher准备默认值为2，与旧覆盖运行一致 |
| 失败与恢复 | 沿用成功响应缓存、有界重试／费用尝试记录、逐条检查点和失败保留 |
| 并发 | 同单元串行，不同单元可并发；同条选择与翻译不并行 |

当前计划没有像旧游戏coverage那样提供原生身份侧表。仅靠现有图关系解析，2420个计划处理状态中331条带topic_id、77条带speaker_id；只有3个主题组含至少5条已选源文、14个角色组含至少2条。它们只是源侧潜在机会，不是已生成摘要／角色笔记数量，也不保证实际候选曝光。
