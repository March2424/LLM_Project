## 原生身份与条件

native_bindings.json只读取源文与provenance，不读取参考译文。Flare以模块/NPC资源文件/明确npc_name及utterance_role=npc绑定说话人，玩家台词不会被标成NPC；同名跨文件不自动合并。像素地牢以原生对象键和可定位的NPC调用来源绑定，来源不足不补造人物身份。主题限明确对象资源、NPC对话资源或源侧叙事文档，不把任意引擎代码文件当语义主题。

绑定保留源版本、原文hash、原生路径/行号。GraphRetriever在有效源记录上应用只读元数据，不重写源CSV、源SQLite或原有实体图。原来的branch/phase/requirements约束保持，分组严格使用相同已知条件，不靠放宽作用域拼样本。未知信息仍为unknown；原生绑定模式没有明确说话人时，不再用模型图的猜测回填说话人。

旧128条冻结观察与历史不回填这些新身份。新增分组只使用后续未生成原文，因此不会把旧译文强行改成过去已经有的角色笔记/摘要。

## 记忆如何出现

coverage运行将style_min_examples设为2。角色笔记依据同一明确角色、兼容条件下至少2条不同源文；后续每积累2条新证据可刷新，窗口最多6条。笔记保留来源与依赖，只描述有据的表达方式，不推断永久性格。正常记忆更新仍在当前Teacher选择完成、独立基线翻译写回之后。

摘要沿用summary_step=5；前5条本run兼容译例形成主题摘要，第6条及以后才有机会观察。源侧和目标侧内容来自已允许的源证据与本run已提交译例，不使用未来译文或人工参考。

候选池继续允许术语/角色合组、STM/LTM合组，池16、软选择最多8、1024软token不变。Teacher仍可跳过不适用、重复或质量不足的角色/摘要，不增加最终选择配额或覆盖奖励。

## 实际覆盖检查

progress.json/HTML新增candidate_available_targets_by_kind与selected_targets_by_kind，区分“没有召回”和“Teacher未选”。export.json也记录实际可见数量。coverage运行若仍无style或summary候选，会保留原始候选审计，但拒绝直接写入注册训练集，要求先检查记忆形成。

SFT只学习选择分析/动作，不再以参考译文可用性限制这些源侧分组；参考仍独立存放。后续DPO使用参考式评分时，必须按manifest另选合格训练参考，不能把无参考状态直接送sCOMET。
