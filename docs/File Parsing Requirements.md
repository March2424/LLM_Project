# Game Localization — File Parsing Requirements

需要解包游戏的原文以及翻译，优先中文

## 已明确的文本范围（2026-10-29）

目标是游戏中各类需要本地化的可见文本，包括剧情对话/旁白、UI（菜单、按钮、设置、提示、错误消息）、物品/装备名称与说明、技能/属性/状态名称与说明、任务/日志、人物/地点名称，以及思维、教程、成就等游戏特有文本。不能只以 dialogue 数据库作为完整输入。

统一记录文本类别与字段用途（如名称、说明、按钮、提示），并保留原始 key、资源位置及可证实的实体关联；说话人、场景、对话节点和分支仅在适用时填写。UI 和物品文本不因缺少对话字段而被丢弃。图片内文字作为覆盖清单中的独立待核查项，不能把 OCR 结果当作已对齐的官方文本。

验收按类别分别报告原文条数、中文对齐数、缺译/冲突及未取得范围。现成网站的对白或物品页面只能证明该类可查看，不能证明已覆盖完整 UI 或全游戏文本。
