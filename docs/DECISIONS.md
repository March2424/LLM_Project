## M2-001：DelTA 记忆适配（2026-10-28）

- 依据：用户要求基于 DocMTAgent 构建记忆模块；延续 README 的 SQLite、证据与版本设计。
- 选择：参考 DelTA 四类记忆，移植中英摘要提示词；用标准库 SQLite 保存正文和版本，用可注入模型接口替代上游全局模型客户端。
- 原因：先交付可独立验证和集成的 M2，避免记忆底座依赖尚未确定的 GPU/API 资源。STM/LTM 共用译例正文，图与向量索引后续由 M3 扩展。
- 差异：默认无模型词法基线；DelTA 式 agent 检索可配置。知识生成结果需要审核，译例需要绑定候选的检查回执；不把此次实现标为原版实验完整复现。
- 影响：M1 使用共享 Occurrence；M3/M4 消费 MemoryBundle；M5 提供真实检查与模型后端；M6 接续完整维护；M7 后续验证质量。
- 边界：本轮未实现角色自动提取、Loong 训练、图检索、跨文档 seed TM 或真实翻译评测。
- 关联交付：[MEMORY.md](MEMORY.md)、[INTERFACES.md](INTERFACES.md)、[第三方来源](../THIRD_PARTY_NOTICES.md)。当前为本地实现，未创建提交或 PR。


## M3-001：游戏图与无结构 CSV（2026-10-28）

- 任务依据：实现 TransGraph 启发的图搜索，支持不同实体关系及无场景/章节 CSV。
- 决策：SQLite 与 M2 共库；图节点/关系独立版本及快照。实体子类型开放，关系通过带端点约束的不可覆盖注册定义扩展；事实单独审批和作用域过滤。
- CSV：显式源侧列映射和人工 annotations；无章节以 source-unit 标记，无场景保留未知；默认技术分块、顺序不可信，不隐式生成语义连续性。稳定 key 优先，无 key 时显式行号模式且冻结文件 namespace。
- 联动：M2 暴露 eligible，图召回可读取窗口外兼容译例；输入清单区分图、源文、记忆引用。提交保存源版本依赖，图失效传播到使用它的 TM。
- 首版预算为字符数，固定有界遍历和选择；自动提取、完整规则解析、学习选择与 token 预算后续完成。已有离线验证不代表真实模型效果。
- 影响：M1 源文组织、M2 读取/提交、M3 候选和打包、未来 M5/M6。接口见 INTERFACES.md，使用见 GRAPH.md。
